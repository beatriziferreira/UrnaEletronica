# PROJETO URNA ELETRÔNICA!
  Como esse ano é de eleições, resolvi criar um projetinho imitando a urna eletrônica em Java!

  Esse projeto vai ter duas versões: uma em que os candidatos são inicializados com um número aleatório de votos (para mostrar que os métodos de ordenar e imprimir os resultados estão funcionando corretamente) e na outra todos inicializam com 0 votos, como uma urna recém ligada.
